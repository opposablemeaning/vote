# VOTE. THEM. OUT.

A get-out-the-vote video for the **Tuesday, Nov 3, 2026** midterms, and every receipt behind it.

**Check your registration: [vote.org](https://www.vote.org/am-i-registered-to-vote/)**

**The receipts:** [opposablemeaning.com/vote](https://opposablemeaning.com/vote/). Every claim in the video is on that page, with its source. Paused on an EXHIBIT number? Find it there.

## What's here

| Path | What |
|---|---|
| `data/receipts.json` | The single source of truth: every claim, with status, outlet, date, and URL |
| `data/hero.exhibits.json` | EXHIBIT number → source, in on-screen order (generated by the video build) |
| `docs/` | The receipts site (generated by `scripts/build-site.mjs`; Cloudflare Pages serves `docs/`, page at `/vote/`) |
| `templates/hero.html` | The video: an HTML + GSAP composition rendered with [HyperFrames](https://www.npmjs.com/package/hyperframes) |
| `scripts/build-hero.mjs` | Lays the receipts out on a 135 BPM beat grid; writes the composition and the audio cue sheet |
| `scripts/render_track1b_master.py` | Builds the hero soundtrack: synthesized music (`track_engines.py`), sound effects (`sfx_organic.py`, synthesis plus CC0 one-shots), the voice clips, ducking and the master |
| `scripts/sfx.py`, `music.py`, `kits.py`, `mix.py` | The earlier synthesized sound set; `mix.py` still builds the Shorts' soundtracks |
| `scripts/ccc_dots.py` | No Kings protest locations from the Crowd Counting Consortium dataset |

## Status labels

Every receipt says what kind of evidence it is:

| Label | Meaning |
|---|---|
| `QUOTE` | Their own words, from a recording, transcript, or post |
| `COURT RULING` | A judge, grand jury, or court decision |
| `COURT ORDER` | An interim court order (e.g. the ICJ's provisional measures), not a final ruling |
| `COURT FILING` | An allegation in a court filing, such as an indictment |
| `OFFICIAL` | A government record: a vote tally, an order, an agency release |
| `REPORTED` | Reporting by a news outlet |
| `DATA` | Published statistics |
| `ESTIMATE` | A projection or model (CBO, KFF, researchers), labeled as one |
| `PROPOSED` | Proposed, not done |
| `LAW` | Enacted law |

## Build

```sh
npm install                       # map data (us-atlas, topojson-client, d3-geo)
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
node scripts/build-hero.mjs --site-live          # composition + cue sheet (add --after-oct17 after Oct 17)
.venv/bin/python scripts/render_track1b_master.py  # soundtrack -> hero/assets/audio/mix.wav
node scripts/build-site.mjs                        # receipts site -> docs/
cd hero && npx hyperframes@0.8.143 render --quality looks --output ../out/hero.mp4
```

The video build also expects a few media files that aren't in this repo: the two Trump audio clips in `assets/clips/` (used under fair use for commentary), and the CC0 field recordings and drum samples listed in `assets/audio/CREDITS.md`. Without them, the mix skips those clips with a warning.
